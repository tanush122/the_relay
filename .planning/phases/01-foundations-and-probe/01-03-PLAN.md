  relay/llm.py (target ~75 lines; docstring: why streaming — TTFT is what the person feels; why every header is kept verbatim — Table 1 and the gateway are built from them; why one base URL — the stand-in swaps in unchanged). Plain functions:
  - load_api_key() -> str: os.environ["GROQ_API_KEY"] if set, else parse config.ENV_PATH line by line for a `GROQ_API_KEY=` prefix (stdlib only, no python-dotenv); return "" if absent. Never print or log it. Per ENV-02.
  - redact(text) -> text with any match of r"gsk_[A-Za-z0-9]+" replaced by "gsk_[REDACTED]". Applied to every string written to traces (error bodies, exception text).
  - estimate_tokens(text) -> int(len(text.split()) * config.TOKENS_PER_WORD) + 8 (comment: rough, real counts come from usage).
  - check_spend(estimate, confirm, cap) per ENV-05: always prints "Estimated spend: {estimate} tokens" first; if not confirm -> prints "Refusing real call: pass --confirm after reviewing the estimate" and raise SystemExit(2); if cap is None -> "Refusing: pass --max-tokens-total N" and SystemExit(2); if estimate > cap -> "Refusing: estimate exceeds cap" and SystemExit(2).
  - make_client() -> httpx.AsyncClient(timeout=httpx.Timeout(config.READ_TIMEOUT_S, connect=config.CONNECT_TIMEOUT_S)).
  - async list_models(client, api_key, base_url=None) -> record dict: GET {base}/models with Bearer auth; record status, headers, model ids (if 200), error_body, total_ms. Free call (no tokens).
  - async stream_chat(client, model, messages, max_tokens, api_key, base_url=None, extra=None, on_content=None, tag=None, trace_path=None) -> record dict. Body: model, messages, max_tokens, stream True, plus config.MODEL_PARAMS.get(model, {}) and extra. Uses client.stream("POST", ...); time.perf_counter from just before send. Record keys exactly: request_id (uuid4 hex), tag, model, url, sent_at (UTC ISO), status, headers (dict of every response header as httpx exposes it), ttft_ms (first non-empty delta.content), first_reasoning_ms (first non-empty delta.reasoning, else None), total_ms, content (joined), reasoning_chars, delta_keys (sorted union of keys seen in deltas), usage (chunk["usage"] or chunk["x_groq"]["usage"], last seen), x_groq (last x_groq object seen), final_chunk (last parsed JSON chunk), error_body (redacted response text when status != 200), exception (redacted "Type: message" on network errors/timeouts, record still returned). Call on_content(text) for each content delta so callers can print as it streams. If trace_path is given, write_trace(record, trace_path).
  - write_trace(record, path): mkdir parents, append json.dumps(record) + "\n". Request headers are never recorded, so Authorization never reaches disk.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| laptop -> Groq API | key sent as Bearer header; responses are untrusted input |
| process -> disk (traces) | anything written to data/traces may be committed and submitted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information disclosure | traces / error bodies | mitigate | request headers never recorded; redact() applied to error_body and exception text; test asserts key string absent from trace line |
| T-03-02 | Information disclosure | stdout | mitigate | load_api_key result never printed; grep acceptance check on relay/llm.py |
| T-03-03 | Denial of service (own quota) | ask.py real mode | mitigate | refuse before any work unless --confirm and --max-tokens-total; check_spend prints estimate and rejects estimate > cap |
| T-03-04 | Tampering | SSE parsing of untrusted stream | mitigate | json.loads per data line, unknown keys ignored, malformed line recorded via exception field rather than crashing silently |
| T-03-05 | Spoofing | base URL override | accept | RELAY_BASE_URL is local developer config only; default is Groq HTTPS |
</threat_model>
