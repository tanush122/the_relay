Spaced stage sleeps spaced_interval_s between requests. Bursts and concurrency groups use asyncio.gather (truly concurrent). Recovery stages: only run if the preceding burst produced a 429; poll every recovery_poll_interval_s until the first 200 or recovery_max_polls; summary records seconds from the burst's first 429 to that first 200 (key recovery_rpm_s / recovery_tpm_s, None if never recovered). Summary also stores cap, spent, requests_sent, stopped_reason ("done" if finished), base_url host only, and the plan's estimated total. No key in any file.

  - build_table1(records, summary) -> list of 7 dicts with keys Limit, Value found, How found, Confidence, rows in this exact order: "Requests per minute", "Tokens per minute", "Requests per day", "Tokens per day", "Requests in flight at once", "What it returns when a limit is hit", "Time until it recovers". Rules:
    - Requests per day: distinct x-ratelimit-limit-requests values per model ("model=value; ..."); How found "x-ratelimit-limit-requests header on N responses (docs: per-day)"; Confidence "medium" (header meaning taken from Groq docs) or "not measured".
    - Tokens per minute: same from x-ratelimit-limit-tokens; if a 429 body names TPM with "Limit N", add it and raise Confidence to "high".
    - Requests per minute / Tokens per day: regex r"\((RPM|TPM|RPD|TPD)\): Limit (\d+)" over error_body of 429 records; value from the body (Confidence "high", How found "429 body during <stage>"); for RPM without such a body but with a burst 429, value "<= burst size, exact unconfirmed" from the count of 200s before the first 429, Confidence "low"; otherwise "not measured" with How found "not in headers; read limits page or confirm in phase 4".
    - Requests in flight at once: from concurrency records: largest level where every request returned 200, with median TTFT per level in How found; Value ">= L (no cap observed up to L)" Confidence "low"; or "not measured".
    - What it returns: first 429 record: "HTTP 429, retry-after: X, error type: T" with the message (trimmed to ~120 chars); Confidence "high" if observed, else "not measured".
    - Time until it recovers: summary recovery_rpm_s / recovery_tpm_s and the observed retry-after; Value e.g. "RPM: 12.3 s; TPM: not measured"; How found "polled every Xs until first 200"; Confidence "medium" (poll granularity), "not measured" if absent. Daily recovery is always noted as "daily reset not measured (phase 4)".
  - render_markdown(rows) -> markdown table with header "| Limit | Value found | How found | Confidence |".
  - main(argv): optional run_dir argument; prints the table and writes run_dir/table1_draft.md. With no probe runs at all, print a 7-row table of "not measured" and say no probe has been run (do not error).
